How to Add AETHER to Chrome

Load AETHER in under 60 seconds with Chrome Developer Mode.

01

Download Extension

Download the latest extension files from the official GitHub repository:

Download .ZIP
git clone https://github.com/codewithayan008/AETHER-Extension.git

Extract the downloaded ZIP to an easily accessible folder on your computer.

02

Open Chrome Extensions

Open Google Chrome and navigate to the extensions manager by typing:

chrome://extensions

Toggle the Developer mode switch in the top-right corner to ON.

03

Click "Load Unpacked"

Click Load unpacked in the top-left toolbar, then select the extracted folder:

AETHER-Extension unzipped folder

Select the folder (the one containing manifest.json) and click Select Folder.

04

Open a New Tab

Press Ctrl + T (or Cmd + T) to open a new tab.

AETHER immediately replaces the blank tab with your spatial glass workstation and active Shield protection!

AETHER Shield Engine

Private by architecture, not by promise.

Most extensions promise privacy while actively collecting your browsing habits. AETHER Shield works differently: it never requests the history permission and performs all content filtering using native Chrome declarative rules.

  • Zero Payload Snooping: Extension scripts never inspect or store the contents of your HTTP packets.
  • Native Network Layer: Rules execute inside Chrome's C++ network stack for maximum speed and zero memory overhead.
  • Instant Allowlist: Easily exempt trustworthy sites directly from the toolbar popup.
